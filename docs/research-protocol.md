# Research protocol

Afterlight uses a reviewed experimental template, structured records and mechanical execution checks. It does not treat an agent persona as evidence of scientific rigor.

1. Record source identity, version, passage, query and search time. Distinguish author findings from agent proposals. A search has limited coverage and cannot prove that a problem is open.
2. State the question, intervention, comparison, competing explanation and primary outcome before evaluation. State the true independent unit, observation surface, uncertainty method, controls and transfer limits.
3. Calibrate on separate cases. Save failed and abandoned candidates. Do not tune the final evaluation to obtain a desirable result. Use the real clock for freeze timestamps.
4. Freeze the exact contract, prompts, cases, model, provider route, settings, output caps and stopping rule. Hash the frozen artifact. Changed measurements or conditions require a linked new version.
5. Validate controls and the scoring path. An explanation judgment is fallible. Causal influence requires a controlled comparison, not a plausible interpretation of one response.
6. Reserve a conservative allowance before each external call. Reconcile returned usage. Missing billing information is provisional, never zero by default. Pause ambiguous paid-call outcomes instead of blindly repeating them.
7. Persist run state, immutable trial identities and raw observations outside the agent conversation. Complete a trial once. Preserve failures and missing data in denominators and reports. Recovery must not silently skip a running trial.
8. Analyze all frozen evaluation cases. Repeated calls to the same task do not create new task-level replications. Use uncertainty appropriate to the design and report when sampling assumptions limit interpretation.
9. Attach evidence to the question with a scoped conclusion. A null result is not proof of equivalence. A small adaptation is not a full benchmark replication. A recorded run is labeled recorded.
10. Publish a reproducible package with contract, prompts, inputs, output observations, scoring, dependencies, costs, deviations and limits. Public participation never authorizes expenditure of owner credits.

The rule engine can enforce hashes, state transitions, authorizations, IDs and budgets. It cannot prove semantic relevance, completeness of literature coverage or validity of a research interpretation. Those judgments remain reviewable and fallible.
